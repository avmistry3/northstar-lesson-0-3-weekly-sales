# Weekly Sales Summary

A small Python script that summarizes weekly sales data for the LinenLane retailer. the script will produce a printed report  

## What it does

The script defines a dictionary of weekly sales data and it calaclate total , avegrage and classify week according above average or sales number is greater than or equal to the average or below average otherwise. summary section is showing total, average, the highest week, lowest week. 

# lessons learn 
  Writes the entire report to a file called weekly_sales_report.txt using a with open(...) block.
## How to run

You need Python 3.10 or higher. From the terminal, in this folder:

    python weekly_sales_report.py

(On Mac and Linux you may need `python3` instead of `python`.)
